# AI Council

Приложение для Android, реализующее мультимодельные дебаты через API OpenRouter с использованием интерфейса Kivy.

## Возможности
- Динамический каталог моделей OpenRouter с фильтрацией по бесплатным вариантам.
- Настройка участников, их ролей и выбор независимого судьи.
- Поддержка от 1 до 10 раундов дебатов с автоматической критикой ответов.
- Сохранение истории дискуссий и экспорт результатов в TXT-файлы в приватную память приложения.
- Тёмная тема оформления и встроенные шаблоны тем.

## Сборка APK
Локальная сборка через Buildozer в Termux не поддерживается из-за отсутствия системных заголовочных файлов (`zlib`). 
Основной способ сборки — **автоматический через GitHub Actions**:
1. Запушьте изменения в репозиторий (`git push`).
2. Перейдите на вкладку **Actions** на GitHub.
3. Скачайте готовый `.apk` из раздела **Artifacts** после завершения сборки.

## Безопасность
- API-ключи хранятся локально в защищенной приватной папке приложения на устройстве.
